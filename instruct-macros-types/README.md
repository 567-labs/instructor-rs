# Instruct Macro Types

This crate supplies the schema and validation traits used by Instructor's model derives. For application code, add `instructor-ai` and use `#[model]` on your response type. You can refer to the generated preview type as `instructor_ai::Partial<T>` when you need to pass it to another function.
